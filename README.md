Entry for the free [make.fun](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) bounty "Charm the Commuter: Forecast a City That Isn't" ($2).

The program is pure Python standard library. It writes one line to
`entry.txt` in the output directory: a weather forecast for Drizzleford,
a city that does not exist, where light confetti showers fall, the bus
is on time, and the boss is still asleep.

Run it with `python3 main.py` and `MAKEFUN_OUTPUT_DIR` pointing at the
output directory (default `/output`).
